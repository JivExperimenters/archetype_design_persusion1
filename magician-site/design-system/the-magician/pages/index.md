# Page override: index (the only page)

Overrides MASTER.md where they disagree. Set from Minh's brief, not the engine.

- **Approach: postmodern, Memphis-inspired** (per the team's lesson 02): asymmetry, overlap, playful geometry, cutout/collage, tilted panels, unexpected juxtaposition (Bosch next to a vacuum cleaner), expressive display type with readable supporting text. Memphis grammar in Minh's palette: no rainbow.
- **Rule: the frame plays tricks, the message doesn't.** Images, frames, stickers and shapes may tilt up to 8deg. Anything holding a paragraph tilts 1.5deg max (0 on mobile). Body copy is always straight and legible.
- **Mode:** light only, plus one dark "slide" (My take).
- **Accent:** warm, not teal. Ember `#C2410C` (4.5:1 on Paper, AA for text). On the dark slide use Ember-light `#F0834F`.
- **Palette:** Paper `#F4F0E8` bg · Paper-2 `#FBF8F2` cards · Stone `#E9E2D6` surfaces · Line `#DDD4C6` borders · Soft ink `#5B5349` secondary text · Ink `#1D1A16` text and dark slide bg.
- **Type:** Newsreader Variable (serif) for display, headings, pull quotes, big numbers. Geist Variable (sans) for body and UI. Not Roboto.
- **Motion:** element-level only (hover, load entrance). Never touch the user's scrolling. Respect prefers-reduced-motion.
- Avoid: muted + low energy. Neutral base, but the accent, the geometry and the dark slide carry energy.
